:::warning Not available for v5.0.0 yet
HOPRd v5.0.0 isn't published as a `.deb`, `.rpm` or `.pkg.tar.zst` package yet. Packages on older release pages install v3.0.0, which doesn't run on the v5 network.

To run a v5 node on Linux, use one of these setups:

- [Docker](./node-docker.md)
- [Docker Compose](./node-docker-compose.md)
- [Binary](./node-binary.md)

This page will be updated when v5 packages are available.
:::
