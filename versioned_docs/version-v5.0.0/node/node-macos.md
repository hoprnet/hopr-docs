:::warning Not available for v5.0.0 yet
There is no native macOS build of HOPRd v5.0.0 yet. The Homebrew formula `hoprd@3.0.0` installs v3.0.0, which doesn't run on the v5 network.

To run a v5 node on a Mac, install [Docker Desktop](https://www.docker.com/products/docker-desktop/) and follow the [Docker](./node-docker.md) or [Docker Compose](./node-docker-compose.md) guide.

This page will be updated when a native v5 build is available.
:::
